# Sovranly IP Developer Guidelines

- **Project Identity**: Always refer to the platform as **Sovranly IP** (never Pulse).
- **Core Vision**: Empowerment of creators, blockchain-based IP management, and **Zero Trust Architecture**.
- **Tech Stack**: Next.js 15+, TypeScript, Tailwind CSS, shadcn/ui.
- **Security**: As a Zero Trust application, all data access, API calls, and smart contract interactions must be authenticated, authorized, and continuous.
- **Interactive UI**: Maintain the professional, dark-themed, data-rich aesthetic.
